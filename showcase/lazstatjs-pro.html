LazStats Pro v0.35.0

L'evoluzione desktop e agentica di LazStats JS: oltre 70 procedure statistiche, report e grafici esportabili, CLI e server MCP. Tutto in locale, con i calcoli sempre visibili.

🔗 GitHub 🚀 Release 0.35.0 📄 README

📖 Cos'è

LazStats Pro è l'evoluzione desktop di LazStats JS. Porta lo stesso principio — analisi statistica trasparente e locale — in un workbench completo: oltre 70 procedure in 12 famiglie, griglia tipizzata, import CSV/TSV/JSON/XLSX e SPSS/Stata, progetti .lzs, report discorsivi, grafici editabili ed export HTML, Word e XLSX. La release 0.35.0 aggiunge la CLI lazstats e il server MCP lazstats-mcp, rendendo le analisi richiamabili anche da agenti AI.

👤 A chi serve

LazStats Pro è pensato per ricercatori, studenti e analisti che vogliono procedure statistiche solide senza affidare i dati a un servizio cloud. È utile a docenti che devono mostrare tabelle, diagnostica e assunzioni in modo leggibile, e a sviluppatori di agenti che cercano un motore statistico locale, documentato e senza effetti collaterali sul filesystem. Chi ha iniziato con LazStats JS ritrova lo stesso approccio, con più profondità e strumenti di automazione.

🚀 Novità della 0.35.0

1. CLI lazstats: catalogo, schema, ispezione, run, batch e rendering dei risultati, con envelope JSON e help esauribile anche in formato macchina.
2. Server MCP lazstats-mcp: otto tool stdio per far scoprire, ispezionare ed eseguire analisi a un host agentico, senza rete, shell o scritture su disco.
3. Capacità agentica: l'agente può leggere solo la directory concessa con --root, eseguire un run-report e recuperare tabelle, prosa e grafici; i risultati restano in cache e possono essere renderizzati.
4. Interfaccia: gruppi di comandi colorati con contrasto accessibile, temi Midnight color e Misty color, toolbar Dati/Progetto e autosave nella status bar.

🧰 Capacità agentiche

Il server MCP espone il motore statistico a host come Claude Desktop, Cursor o qualsiasi client compatibile. Non è un chatbot dentro l'app: è un contratto di tool che permette a un agente di orchestrare analisi riproducibili.

ToolCosa permette
engine_infoVersioni, capacità, limiti e topic di help
list_analysesCatalogo delle procedure disponibili
describe_analysisRuoli, default, parametri e contratto di una procedura
inspect_datasetColonne, tipi e anteprima limitata del dataset
run_analysisEsegue una procedura da path, progetto o dati inline
get_resultRecupera le sezioni del run-report dalla cache
render_chartRestituisce specifiche o SVG dei grafici
validate_projectValida un progetto .lzs in sola lettura

✨ Caratteristiche

  • Oltre 70 procedure — Descriptive, compare, regressione, multivariata, survival, time series, quality, DOE, ML e advanced.
  • Report leggibili — Tabelle, prosa, diagnostica e grafici nello stesso run-report, esportabili in HTML, Word e XLSX.
  • Local-first — Nessun backend e nessun cloud: i dataset restano sulla macchina.
  • Sei lingue — Interfaccia, help e report in italiano, inglese, francese, spagnolo, tedesco e portoghese.
  • Temi accessibili — 13 temi built-in, inclusi Midnight color e Misty color, con contrasto verificato.
  • Runtime autonomi — Tarball lazstats e lazstats-mcp allegati alla release GitHub.

🔒 Privacy & Sicurezza

  • Dati locali — Nessun upload e nessuna telemetria.
  • MCP in sola lettura — Il server non esegue shell, eval o scritture su disco.
  • Perimetro esplicito — L'agente accede solo alla directory passata con --root.
  • Risultati riproducibili — Parametri, versione del motore e metadati accompagnano ogni run-report.
