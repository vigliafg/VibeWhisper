✨ Cos'è pdfextractor

pdfextractor (package pdf_to_md) è un convertitore CLI Python che trasforma PDF scientifici — anche quelli con layout a due colonne — in file Markdown puliti e semanticamente strutturati. Usa Docling di IBM Research per l'estrazione del contenuto, con ottimizzazioni specifiche per ambienti CPU-only e macchine con meno di 4 GB di RAM.

🎯 Problema Risolto

I PDF scientifici e accademici sono notoriamente difficili da convertire in testo strutturato. Layout a due colonne, tabelle complesse, note a piè di pagina, formule ed equazioni, parole sillabate a fine riga — tutti ostacoli che rendono il copia-incolla un incubo. pdfextractor affronta ognuno di questi problemi con una pipeline dedicata.

🔧 Funzionalità Principali

  • Ricostruzione Strutturale — Linearizza layout multi-colonna preservando l'ordine di lettura corretto
  • De-hyphenation Automatica — Ricongiunge le parole spezzate a fine riga (es. "conver-\ntire" → "convertire")
  • Conversioni Tabelle — Trasforma tabelle complesse in tabelle Markdown perfettamente allineate
  • Estrazione Immagini — Salva automaticamente le immagini in una cartella images/ con riferimenti nel Markdown
  • Output Pulito — Markdown semanticamente corretto con heading, paragrafi, liste, blockquote

⚙️ Ottimizzazioni Low-Resource

A differenza di molti convertitori PDF che richiedono GPU e 16+ GB di RAM, pdfextractor è progettato per funzionare su qualsiasi laptop. Le ottimizzazioni hardcoded in converter.py:

  • CPU-only — PyTorch installato con indice CPU, nessuna dipendenza CUDA
  • Single-threading — Forza l'uso di un solo thread per evitare memory spike
  • Batch size = 1 — Elaborazione pagina per pagina invece che a lotti
  • Backend pypdfium2 — Rendering PDF più efficiente rispetto ad alternative più pesanti

🖥️ Utilizzo

# Installazione (ambiente virtuale consigliato)
python3 -m venv venv
source venv/bin/activate
pip install docling --extra-index-url https://download.pytorch.org/whl/cpu
pip install "typer[all]" rich pypdfium2

# Conversione base
python -m pdf_to_md.cli documento.pdf

# Con percorso di output personalizzato
python -m pdf_to_md.cli documento.pdf -o output/risultato.md

🏗️ Architettura

Il progetto ha una struttura minimale e modulare (4 file Python):

  • cli.py — Interfaccia a riga di comando con Typer. Gestisce argomenti (path, output) e orchestrazione
  • converter.py — Core della conversione. Configura Docling con le ottimizzazioni low-resource e gestisce il pipeline di estrazione
  • utils.py — Funzioni di supporto per pulizia testo, de-hyphenation, e post-processing del Markdown
  • __init__.py — Package marker

🧪 Testing

Suite di test unitari in tests/test_converter.py che verificano la corretta conversione di PDF campione con layout semplici e multi-colonna.

🔒 Privacy

100% locale. Tutta l'elaborazione avviene sulla tua macchina. Nessun upload a server, nessuna API cloud — il PDF viene letto dal filesystem e il Markdown viene scritto sul disco locale.
