RcmdrShiny Studio v3.2.0

Non un clone pixel-per-pixel di R Commander, ma un workbench statistico browser-native: menubar desktop, command palette, Data e Chart Studio, report e progetti versionati. Stesso motore Rcmdr, stessa promessa: ogni azione lascia un comando R visibile.

📖 Cos'è

RcmdrShiny Studio è la seconda generazione del progetto RcmdrShiny: un workbench statistico locale che gira nel browser. Mantiene il motore e la semantica dei comandi di R Commander 2.15.0, ma sostituisce la metafora desktop/Tk con una Studio nativa: menubar orizzontale, command palette, cronologia strutturata, workspace per dati, grafici e report, più una Classic mode per compatibilità. La release 3.2.0 aggiunge la galleria Examples con 28 ricette offline tratte dall'R Graph Gallery e otto nuovi tipi di grafico ggplot2.

👤 A chi serve

Per analisti e ricercatori che vogliono la potenza di R con un'interfaccia desktop curata, per docenti che mostrano dati, grafici e comandi nella stessa sessione, e per team che hanno bisogno di progetti riapribili e report riproducibili. È la scelta giusta se ti serve più di una GUI: un ambiente di lavoro con palette dei comandi, cronologia, checkpoint, galleria di grafici e un SDK per estendere i menu senza toccare il core.

⚙️ Come funziona

La shell Studio mostra una vista di workspace alla volta, con un secondo slot opzionale e pannelli Inspector/Preview nascondibili; la menubar è guidata da un registry stabile di menu_id e item_id. Il Chart Studio usa un unico motore ggplot2: il builder visuale genera comandi R, l'anteprima è isolata e con debounce, e la galleria conserva i grafici con round-trip nel builder. Il Report Studio gestisce più documenti con outline cliccabile, celle eseguibili e knit in HTML/PDF/Word. La cronologia strutturata permette di rieseguire un comando, riaprire il dialogo o inserirlo nello script. I limiti sui dati sono dichiarati: sopra 5.000 righe la griglia pagina lato server, sopra 10.000 celle l'editor browser è disattivato.

✨ Caratteristiche Principali

  • Shell Studio — Menubar orizzontale, due slot di workspace, pannelli richiudibili, undo/redo applicativo e dialoghi ridimensionabili
  • Command palette — Ctrl+K su menu, help, dataset, variabili e cronologia, con anteprima del comando R e “To script”
  • Data Studio — Registry dei dataset, ricerca globale, ispettore di colonna, operazioni strutturali riproducibili, checkpoint e dizionario dati
  • Chart Studio — Builder per tipo, 33 tipi più 8 nuovi (lollipop, dumbbell, doughnut, area, ridgeline, beeswarm, radar, parallele), temi e palette
  • Examples offline — 28 ricette dalla R Graph Gallery, con anteprime locali, filtri, ricerca e “Open in builder” senza eseguire codice
  • Report e script — Più documenti, outline sincronizzato, celle eseguibili, template, knit manager e autosave con recovery
  • Progetti e plugin — Progetti .rcmdrproj versionati, bundle export, checkpoint e Plugin SDK v2 con componenti, preset, workflow e template
  • Accessibile — Temi chiaro, scuro, alto contrasto e di sistema, scorciatoie da tastiera e guida interattiva al primo avvio

📦 Installazione

# Requisiti: R >= 4.1
install.packages(c("shiny", "bslib", "DT", "shinyAce", "shinyFiles",
                   "rhandsontable", "RcmdrMisc", "ggplot2", "plotly"))

# Dal clone locale
git clone https://github.com/vigliafg/rcmdr-studio.git
cd rcmdr-studio
R -e 'install.packages(".", repos = NULL, type = "source")'

# Avvio
R -e 'RcmdrShiny::run()'

💡 Casi d'Uso

  • Analisi esplorativa — Import con anteprima, ispettore di colonna e grafici costruiti a mano, con il comando R sempre in vista
  • Reportistica — Documenti R Markdown con celle eseguibili, template e knit in HTML, PDF o Word
  • Didattica — Galleria di esempi e command palette per mostrare il percorso dal menu al codice
  • Progetti lunghi — Autosave, checkpoint, cronologia strutturata e progetti riapribili
