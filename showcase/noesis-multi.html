Noesis Multi

Trasforma la tua lettura in conoscenza pura — reader EPUB con traduzione in streaming via il motore nativo del browser (Chrome, Edge, Firefox), estrazione capitoli ed editor integrato. Zero API esterne, un singolo file HTML.

Vanilla JS epub.js IndexedDB Single Page App Offline-first MIT License
🌐 Live App 📄 README 📖 Install Guide 🔗 GitHub

📖 Cos'è

Noesis Multi è un ambiente integrato di lettura e studio EPUB interamente browser-based — un singolo file HTML di 6500+ righe Vanilla JS. Combina un reader avanzato (15 temi, layout singolo/doppio/scroll, highlight a 3 colori, segnalibri CFI) con un editor WYSIWYG Summernote. La traduzione in streaming sfrutta il motore nativo del browser senza mai inviare testo a server esterni. Include snapshot per versioning documenti, raccolta chunk (testo, immagini, tabelle) ed esportazione in Markdown, DOCX, PDF e JSON. Offline-ready dopo il primo caricamento.

👤 A chi serve

Noesis Multi è pensato per studenti, ricercatori e lettori poliglotti. Ideale per chi studia testi in lingua straniera e deve tradurre interi capitoli senza costi API. I ricercatori possono estrarre capitoli, annotarli e raccogliere chunk per costruire documenti di studio. I lettori occasionali apprezzano 15 temi e la modalità offline. Chi gestisce grandi librerie EPUB beneficia dell'import multiplo in IndexedDB e del salvataggio automatico della posizione. Zero competenze tecniche richieste: basta aprire il file HTML nel browser.

⚙️ Come funziona

Tre ambienti integrati: Biblioteca (import EPUB, griglia cover, snapshot), Reader (iframe epub.js, TOC, 15 temi, highlight CFI, traduzione browser con auto-pause salvataggio), Editor sn56.x (Summernote via postMessage). Workflow: importa EPUB → leggi con traduzione streaming → evidenzia → estrai capitolo → snapshot → raccogli chunk → editor → esporta in PDF/DOCX/Markdown. Due database IndexedDB separati (EpubLibraryDB e noesisDB). Editor standalone disponibile come file HTML separato.

🎯 Caratteristiche Principali

  • Traduzione Intelligente — Streaming nel reader e one-shot nell'editor, sfruttando il motore di traduzione nativo del browser (Chrome Translate, Firefox Translation, Edge Translator). Zero API, zero costi per carattere, nessun dato inviato a server esterni.
  • Privacy Totale «By Design» — Zero server, funzionamento offline, dati solo in locale
  • Personalizzazione Estrema — 15 temi, controllo tipografico (font, interlinea, layout), pagina singola/doppia/scroll
  • Annotazione Professionale — Highlight a 3 colori, segnalibri persistenti (CFI), lookup su dizionari
  • Estrazione Intelligente — Estrai capitoli o rami del TOC in HTML standalone con immagini in base64
  • Sistema Snapshot — Versioning manuale dei tuoi documenti (Origin, Clean, Annot)
  • Editor sn56.x Integrato — WYSIWYG con raccolta chunk dal libro, esporta in Markdown, DOCX, PDF, JSON

🏗️ Architettura

L'applicazione espone tre ambienti distinti, navigabili senza routing:

  • Biblioteca — Griglia libri con cover, import EPUB multipli in IndexedDB, gerarchia capitoli/snapshot, strumenti (import snapshot, open editor)
  • Lettore EPUB — Viewer in iframe con sidebar TOC, toolbar completa, 15 temi, highlight, segnalibri, estrazione capitoli, salvataggio stato
  • Editor Estratti (sn56.x) — Popup esterno con payload JSON, comunica via postMessage con IndexedDB condiviso

🌍 Traduzione in Streaming — Come Funziona

A differenza di altri reader EPUB che integrano API di traduzione a pagamento (Google Translate API, DeepL API), Noesis adotta un approccio radicalmente diverso: sfrutta il motore di traduzione già integrato in ogni browser moderno.

🔧 Meccanismo Tecnico

  1. L'EPUB viene renderizzato in un iframe con l'attributo translate="yes" sui contenuti, abilitando la traduzione automatica del browser
  2. L'utente attiva la traduzione con tasto destro → "Traduci in Italiano" (Chrome/Edge) o tramite l'estensione Firefox Translation
  3. Il browser traduce l'intero capitolo in tempo reale, senza inviare il testo a server esterni (Firefox Translation funziona completamente offline)
  4. La traduzione «scorre» insieme alla lettura — da qui il termine streaming translation

🛡️ Protezione dei Dati (CFI Auto-Pause)

Quando il browser attiva la traduzione, modifica il DOM della pagina aggiungendo tag <font> e wrapper. Queste modifiche corromperebbero i CFI (Canonical Fragment Identifier) usati per salvare la posizione di lettura. Noesis risolve il problema con un meccanismo di rilevamento: la funzione _isBrowserTranslated() controlla la presenza delle classi translated-ltr / translated-rtl e dell'attributo translated sull'elemento <html>. Quando la traduzione è attiva, l'auto-salvataggio della posizione viene sospeso automaticamente, preservando l'integrità dei dati di lettura.

💾 Persistenza Dati

Due database IndexedDB separati: EpubLibraryDB (EPUB, metadati, stato lettore, highlights, bookmarks) e noesisDB (metadati capitoli estratti e snapshot). Nessun dato lascia il dispositivo.

🛠️ Strumenti Ancillari

Noesis è accompagnato dalla suite noesis-epub-tools, un'app React + TypeScript deployata su Vercel che unifica tre strumenti EPUB in un'unica interfaccia web. Sono disponibili anche come file HTML standalone nel repo noesis-multi:

  • epubslimer — Comprimi le immagini nei tuoi EPUB (JPG, PNG, WEBP) con elaborazione parallela ×4 via Canvas API. Slider qualità/peso (10-80%), anteprima dimensione prima/dopo, 100% locale. Modalità Single e Batch nella stessa interfaccia.
  • EpubSplitter Pro — Estrai capitoli specifici da un EPUB in nuovi file autonomi con tutti gli asset. TOC gerarchico (supporto EPUB 2 NCX + EPUB 3 Nav), rewriting automatico di OPF e NCX, raccolta selettiva di immagini/font/CSS.
