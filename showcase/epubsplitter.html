EpubSplitter Pro

Estrai capitoli specifici da qualsiasi EPUB in nuovi file autonomi e perfettamente formattati. Single-file HTML, TOC gerarchico, rewriting OPF/NCX — tutto nel browser.

React TypeScript Vite JSZip DOMParser EPUB 2 + 3
🌐 Live App 📥 Versione Standalone 🔗 GitHub

✨ Cos'è EpubSplitter Pro

EpubSplitter Pro fa parte della suite noesis-epub-tools (React + TypeScript + Vite, deploy su Vercel). Carica un EPUB, esplora il suo indice gerarchico (TOC), seleziona il capitolo che ti interessa e ottieni un nuovo EPUB autonomo con SOLO quel contenuto — OPF riscritto, NCX rigenerato, asset (immagini, font, CSS) preservati.

🎯 Workflow

  • Carica l'EPUB — Drag & drop o click per selezionare il file
  • Esplora il TOC — Navigator gerarchico con sezioni espandibili, icone file/cartella, metadati del libro
  • Seleziona un capitolo — Click sul nodo desiderato nell'albero dei contenuti (i sotto-capitoli vengono inclusi automaticamente)
  • Estrai! — Premi "Extract Chapter" e scarica il nuovo EPUB autonomo con tutti gli asset

    • 🏗️ Algoritmo di Estrazione

    L'estrazione segue una pipeline in 7 fasi che preserva l'integrità strutturale dell'EPUB:

    • 1. Parsing EPUB — Rilevamento META-INF/container.xml → OPF → metadati, manifest, spine
    • 2. Rilevamento TOC — EPUB 3 Nav Document (prioritario) → EPUB 2 NCX (fallback). Parsing ricorsivo dei navPoint
    • 3. Raccolta HTML — Identificazione di tutti i file XHTML del capitolo selezionato e dei suoi sotto-capitoli
    • 4. Analisi asset — Scansione di ogni HTML per immagini (<img>, SVG, poster), CSS (<link>), font
    • 5. Copia selettiva — Nuovo ZIP con solo i file necessari: mimetype, container.xml, HTML, asset, font, CSS
    • 6. Rewriting OPF — Aggiornamento titolo, pulizia manifest (rimozione item inutilizzati), filtro spine (solo itemref del capitolo)
    • 7. Rigenerazione NCX — Estrazione del navPoint selezionato dall'NCX originale e reinserimento nel nuovo documento

    🖥️ Interfaccia

    • TOC Gerarchico — Nodi espandibili con indentazione proporzionale alla profondità, icone 📁/📄, selezione con checkmark
    • Pannello Metadata — Sidebar con titolo, autore e lingua dell'EPUB
    • Drag & Drop — Upload via trascinamento con validazione .epub
    • Progress bar — 4 fasi visuali: preparazione (0-25%), copia asset (25-60%), rewriting OPF (60-70%), generazione ZIP (70-100%)
    • Reset/Start Over — Pulsante per caricare un nuovo EPUB senza refresh

    🔧 Dettaglio Tecnico: EpubService

    L'intera logica di parsing e manipolazione EPUB è incapsulata in una classe EpubService (~400 righe) definita inline nel file HTML. Supporta:

    • Risoluzione path — Funzione resolvePath() che gestisce path relativi, assoluti, ../, e fragment
    • Parsing NCX — parseNcx() con attraversamento ricorsivo dei navPoint, estrazione label da <navLabel>
    • Parsing Nav — parseNav() per EPUB 3 con selettore nav[epub:type="toc"], parsing ricorsivo di <ol>
    • Raccolta asset — querySelectorAll su img, video, audio, source, SVG image, link[rel=stylesheet] con decode URI
    • Rewriting OPF — Rimozione <item> e <itemref> non più necessari, update titolo
    • XML Serialization — XMLSerializer nativo del browser per rigenerare OPF e NCX

    🔒 Privacy

    100% client-side. L'EPUB non lascia mai il tuo computer. Parsing, estrazione e generazione avvengono interamente in memoria via JSZip e DOMParser. Nessun server, nessun upload, nessuna API esterna.

    📦 Versione Standalone (Single-File HTML)

    Oltre all'app Vercel, EpubSplitter Pro è disponibile anche come file HTML monolitico (~650 righe). React e JSZip sono importati via ESM import maps da CDN, JSZip e Lucide Icons anch'essi da ESM, Tailwind via script tag. L'EpubService (~400 righe) e tutti i componenti React (FileUpload, TocNode, TocViewer, App) sono definiti inline in un unico <script type="module">.
