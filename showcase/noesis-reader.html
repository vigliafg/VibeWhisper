Noesis Reader

Leggere, Capire, Imparare, Presentare — l'unico lettore EPUB che unisce traduzione in tempo reale, raccolta appunti, editor visuale e strumenti di disegno. Due file HTML, zero account, zero server, gratis per sempre.

🌐 Live App 📄 README 🌍 Sito Web 🔗 GitHub

📖 Cos'è

Noesis Reader è un ecosistema completo per la lettura e lo studio di EPUB interamente browser-based. Due file HTML — index.html (Reader + Libreria) e noesis-editor.html (Editor + Appunti) — offrono un'esperienza integrata: leggi con 15 temi e 3 modalità, traduci in streaming con il motore nativo del browser (Chrome, Edge, Brave), raccogli appunti per libro e capitolo, edita documenti con un editor WYSIWYG e disegna diagrammi con Excalidraw. Il tutto senza account, senza server e senza costi. I tuoi dati non lasciano mai il dispositivo.

👤 A chi serve

Noesis Reader è pensato per studenti, ricercatori e lettori poliglotti che vogliono trasformare la lettura in conoscenza attiva. Perfetto per chi studia testi in lingua straniera e ha bisogno di traduzione immediata senza costi API. I ricercatori possono estrarre capitoli, raccogliere passaggi, immagini e tabelle, organizzarli per libro e capitolo, ed esportare in 7 formati. I creatori di contenuti apprezzano l'editor WYSIWYG e l'integrazione con Excalidraw per generare diagrammi. Chiunque apprezzi la privacy totale: nessun account, nessun server, nessun tracking. Basta aprire il file HTML nel browser.

⚙️ Come funziona

Quattro pilastri integrati in un unico ecosistema: Leggere — Libreria con griglia cover, import EPUB con validazione automatica (check integrità, rilevamento DRM), persistenza IndexedDB, e Reader con 15 temi, 3 modalità (pagina singola, doppia, scroll), TOC gerarchico, auto-salvataggio posizione ogni 3 secondi. Capire — Traduzione streaming via motore nativo del browser: nessuna API key, nessun costo, testo mai inviato a server esterni. Imparare — Estrazione capitoli in HTML standalone, raccolta appunti (testo, immagini, tabelle) con filtro per tipo o capitolo, esportazione in 7 formati. Presentare — Editor WYSIWYG completo + Excalidraw per diagrammi e schizzi, tutto locale.

🎯 Caratteristiche Principali

  • Libreria EPUB — Importa EPUB con validazione automatica (integrità, DRM, struttura). Griglia cover ordinata per data, storage persistente, barra spazio disponibile in tempo reale. Tema chiaro/scuro con preferenza salvata.
  • Reader Professionale — 15 temi in 6 categorie (dal bianco puro al nero notte), 3 modalità (singola/doppia/scroll), TOC gerarchico navigabile, auto-salvataggio posizione, segnalibri con etichette personalizzate.
  • Traduzione Streaming — Sfrutta il motore di traduzione nativo del browser Chrome/Chromium. Traduci mentre leggi, senza interruzioni, gratis e senza limiti. Auto-pause salvataggio CFI quando la traduzione è attiva.
  • Raccolta Appunti — Raccogli testo, immagini e tabelle durante la lettura. Ogni elemento è etichettato con libro e capitolo. Filtra per tipo o capitolo ed esporta in TXT, Markdown, MD+ZIP, DOCX, JSON, PDF, HTML.
  • Editor WYSIWYG — Word processor completo nel browser: scrivi, formatta, inserisci tabelle e immagini. Comunica con la Libreria via postMessage e IndexedDB condiviso.
  • Excalidraw Integrato — Versione ricostruita da zero per Noesis: solo il motore di disegno originale, niente cloud, niente account, niente condivisione in rete. I tuoi schizzi restano sul computer. Export SVG e PNG.
  • 100% Privacy — I tuoi libri e appunti restano sul tuo computer. Niente lascia il dispositivo. Zero server, zero account, zero tracking. Storage persistente richiesto automaticamente al browser.
  • Strumenti Ancillari — EPUB Tools (slimmer e splitter), Pandoc Online (conversione universale via WebAssembly) e Mozilla PDF.js, tutto dal dropdown TOOLS della Libreria. 100% nel browser.

🌍 Traduzione in Streaming — Come Funziona

A differenza di altri reader EPUB che integrano API di traduzione a pagamento (Google Translate API, DeepL API), Noesis adotta un approccio radicalmente diverso: sfrutta il motore di traduzione già integrato in ogni browser Chromium moderno.

🔧 Il Meccanismo

  1. Apri un EPUB — Carica il tuo libro in Noesis Reader
  2. Clic destro → «Traduci in italiano» — O in qualsiasi altra lingua supportata dal browser
  3. Leggi in streaming — Chrome/Edge/Brave traducono ogni pagina mentre scorri, senza inviare testo a server esterni

🛡️ Protezione dei Dati (CFI Auto-Pause)

Quando il browser attiva la traduzione, modifica il DOM della pagina. Queste modifiche corromperebbero i CFI (Canonical Fragment Identifier) usati per salvare la posizione di lettura. Noesis rileva automaticamente lo stato di traduzione e sospende l'auto-salvataggio, preservando l'integrità dei dati di lettura.

🏗️ Architettura: Due File, Zero Dipendenze

L'applicazione si compone di due file HTML da mettere nella stessa cartella:

  • index.html — Reader + Libreria: importa EPUB, gestisci la collezione, leggi con 15 temi e 3 modalità, traduci in streaming, estrai capitoli e raccogli appunti.
  • noesis-editor.html — Editor + Appunti: editor WYSIWYG per creare documenti, raccogli e organizza appunti da tutti i libri, esporta in 7 formati. Excalidraw accessibile dalla toolbar.

Due database IndexedDB (EpubLibraryDB per EPUB, metadati e stato lettore; noesisDB per appunti e snapshot). Comunicazione cross-window via postMessage. Pronto per Cloudflare Pages, GitHub Pages, Netlify, Vercel.

🛠️ Ecosistema: Strumenti Ancillari

Noesis Reader si completa con quattro strumenti esterni, tutti accessibili dal dropdown TOOLS nella barra della Libreria. Ogni strumento risolve un'esigenza reale del flusso di lavoro:

  • EPUB Tools — Single Slimmer e Batch Slimmer comprimono le immagini degli EPUB prima di caricarli in libreria. Chapter Splitter estrae capitoli come EPUB standalone. Tutto nel browser, zero upload. Live App (Vercel)
  • Pandoc Online — Il convertitore universale di documenti eseguito via WebAssembly. Converti in LaTeX, ODT, RST e decine di altri formati. Zero upload: la conversione avviene nella RAM del computer.
  • Mozilla PDF.js — Il lettore PDF ufficiale di Mozilla (lo stesso di Firefox). Ricerca full-text, zoom preciso, stampa ottimizzata. Perfetto per verificare la qualità dei PDF esportati da Noesis.
  • Excalidraw Editor — Versione standalone creata per Noesis: solo il motore di disegno, niente cloud. Disegna diagrammi e mappe mentali senza uscire dall'ecosistema.
