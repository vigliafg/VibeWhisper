Book Consultant v1.0.0

Assistente desktop alla costruzione di documenti e libri: editor a sezioni collassabili, chat con cinque personalità AI che propongono e non scrivono da sole, versioning live, Second Brain, ricerca web, figure generate ed export in cinque formati.

Python Flet 1.1.4 SQLite Markdown OpenRouter FTS5 Pandoc Mermaid Flet pack
🔗 GitHub 📄 README ✅ Release checklist

📖 Cos'è

Book Consultant è un'applicazione desktop per chi scrive documenti lunghi: un editor a sezioni collassabili dove ogni proposta dell'AI arriva come modifica da approvare, mai come scrittura automatica. Il testo resta in Markdown e in SQLite, il versioning è continuo (flush ogni 1,5 secondi, snapshot compressi, checkpoint espliciti) e la cronologia permette di tornare indietro.

Attorno all'editor vivono cinque personalità specialistiche — Ricercatore, Integratore, Rifinitore, Illustratore, Editore — più un assistente generale che smista le richieste. Ognuna ha prompt, permessi e tool distinti; tutte passano dallo stesso protocollo di proposte, con verifica di hash e revisione prima dell'applicazione.

👤 A chi serve

A chi scrive saggi, manuali e libri e vuole un aiuto che resti sotto controllo: la struttura in sezioni, l'indice, i segnalibri e il focus su una parte del testo sono pensati per documenti che crescono per settimane. A chi lavora con fonti e citazioni: import di PDF e DOCX con pagina, note di ricerca con URL e estratti verificati, controllo che una citazione non sia stata inventata. A chi deve consegnare un file finito: export Markdown, DOCX, PDF, EPUB e HTML con preflight delle dipendenze.

⚙️ Come funziona

1. Struttura: il documento è un albero di sezioni con blocchi tipizzati (paragrafo, titolo, citazione, elenco, tabella, figura, diagramma). Solo le sezioni espanse costruiscono i controlli: il rendering resta leggero anche con centinaia di blocchi.
2. Contesto: l'editor sa quale blocco è attivo, dove sta il cursore e che cosa è selezionato; l'agente riceve il contesto esatto e propone una modifica mirata, non una riscrittura del mondo.
3. Proposte: ogni azione dell'AI è una proposta con precondizioni (hash del blocco, revisione del documento). Si applica o si rifiuta; una proposta obsoleta viene bloccata.
4. Ricerca: il Ricercatore legge le fonti del progetto, cerca sul web con DuckDuckGo dietro guardie SSRF e robots.txt, apre poche pagine per turno e propone note con citazioni verificabili.
5. Immagini: l'Illustratore propone tabelle, diagrammi Mermaid (renderizzati con mmdc o dot) e figure generate dall'API Images di OpenRouter, solo dopo approvazione.
6. Consegna: export con Pandoc e LaTeX, controllo editoriale automatico (doc.analyze), backup ZIP con ripristino, log ruotati senza segreti.

✨ Caratteristiche

  • Editor a sezioni — Collassa, espandi, focus su una sezione, indice e segnalibri persistenti
  • Versioning live — Flush ogni 1,5 s, snapshot zlib, checkpoint manuali e cronologia con diff e ripristino
  • Second Brain — Indice del progetto, ricerca full-text FTS5 e brain.json sempre consultabile
  • Cinque personalità — Ricercatore, Integratore, Rifinitore, Illustratore, Editore, con matrice di permessi distinta
  • Import — PDF, DOCX, HTML, Markdown e testo, con proposta di struttura e fonti archiviate con hash
  • Ricerca web — DuckDuckGo senza chiave, guardie SSRF, rispetto di robots.txt, note con citazioni e pagine PDF
  • Figure e diagrammi — API Images di OpenRouter (1K, fino a 14 reference) e catena Mermaid → DOT → sorgente
  • Export completo — MD, DOCX, PDF, EPUB e HTML con anteprima, indice, figure e preflight delle dipendenze
  • Manutenzione — Backup ZIP ripristinabile, retention delle revisioni, VACUUM, log ruotati con redazione di chiavi e token

🗂️ La filiera del documento

Dalla fonte al file consegnato, ogni passaggio lascia una traccia: la fonte importata ha hash e stato, la proposta ha una revisione di riferimento, l'export crea un checkpoint, il backup contiene database, impostazioni, asset e fonti. 

Import PDF/DOCX ──▶ Fonti (hash, pagine)
        │
        ▼
Editor a sezioni ──▶ Versioning (1,5 s) ──▶ Checkpoint / cronologia
        │
        ├──▶ Ricercatore ──▶ nota di ricerca ──▶ Sorgenti
        ├──▶ Illustratore ──▶ tabella / diagramma / figura
        └──▶ Editore ──▶ doc.analyze ──▶ report
        │
        ▼
Export MD · DOCX · PDF · EPUB · HTML ──▶ Backup ZIP

🔒 Privacy & Sicurezza

  • Chiave fuori dal progetto — Letta da variabile d'ambiente, file con permessi 600 o keyring; mai nel database, nei log o nelle proposte
  • Nessuna scrittura senza approvazione — Ogni modifica passa da una proposta con precondizioni di hash e revisione
  • Web con guardie — URL privati e loopback rifiutati, robots.txt rispettato, materiale esterno trattato come dati e non come istruzioni
  • Log redatti — Rotazione 1 MB × 3, con rimozione di chiavi, token e header Bearer

📦 Release

Versione 1.0.0, con installazione in editable, CI GitHub Actions (lint e test) e pacchetto Linux da flet pack. La checklist di release e il manuale di accettazione sono nel repository. Limiti dichiarati: niente OCR nell'import, un documento primario per progetto, figure e diagrammi non ancora renderizzati inline nell'editor.
